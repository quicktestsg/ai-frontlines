The Transcript Is the Debugger

Every debugging tool ever built answers one question: what happened, exactly, at the moment things went wrong? For agents, the question is unanswerable by default — and the answer is not more logs. It is replay.

A run completes in forty-one steps and produces a subtly wrong result. Every individual step succeeded, including the ones that were wrong. The stack trace is useless here for a structural reason: there is no stack. The causal chain runs forward through time, not downward through call frames.

Agent failures are temporal, not hierarchical. The cause lands early, travels silently, and surfaces many turns later — with every step reporting success. Only a complete record of the run can connect turn 3 to turn 40.

Logs are lossy. Transcripts are the system.

A log line is a summary written by the code that failed — it encodes what the author thought would matter, which is precisely what debugging is trying to discover. A transcript inverts the relationship: nothing is summarized, everything is captured. Storage is cheaper than forensics.

A team that can replay a failure debugs causes. A team with logs debugs opinions. The difference is not skill — it is whether the run still exists after it ends.

Replay changes what a bug report is

Once transcripts exist, debugging stops being archaeology. Load the transcript, step to the failure, step backward until the interpretation diverged from reality. The harness can re-execute any suffix of the run with recorded tool results stubbed in — so an operator tests a fix against the exact world that failed, not a similar one.

The replay motion, end to end: inspect backward from symptom to divergence, re-execute any suffix with recorded results stubbed in, and test the fix against the exact world that failed.

The harness owns capture, or nobody does

Only the harness sees everything, and only the harness is not the thing under investigation. It is the single choke point through which every exchange already flows — recording there misses nothing. And the corollary compounds: transcripts are the audit trail and, mined over time, the raw material that evaluations are made of.

Every exchange an agent makes already passes through the harness. Recording at that choke point is complete by construction, and the same artifact pays out three times: debugger, audit trail, eval corpus.

Replayability does not make agents correct. It makes them accountable to reality — it converts mysterious wrongness into inspectable wrongness, which is the only kind any engineering discipline has ever actually fixed.
