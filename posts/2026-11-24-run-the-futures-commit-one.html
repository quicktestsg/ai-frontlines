Run the Futures, Commit One

Agent loops serialize uncertainty into a single committed trajectory, then spend the whole context defending it. The fix is harness-level speculative execution: branch, rehearse, verify, commit late — and autopsy the losers.

Speculation is the oldest trick in computing, and it works because checking is cheaper than producing. Branch predictors, out-of-order cores, speculative decoding — all accept the same trade: waste some work, never stall on uncertainty. Agent loops accept the opposite trade. A model torn between two plans still emits exactly one, and the wrong branch is not flushed. It is committed.

The serial trap

In hardware, a misprediction costs a nanosecond flush. In an agent loop it compounds on three fronts: tokens spent building on the wrong premise, tool side effects left behind, and context that turns the mistake into established fact. The loop cannot see the path not taken, so the taken path becomes the only world it knows.

Two ways to spend the same uncertainty. The serial loop converts doubt into commitment at choice time; the speculative loop converts it into parallel rehearsals paid for in wasted tokens — a currency that keeps getting cheaper.

The asymmetry that pays for it

Verification is a fraction of the work of generation under uncertainty. A cheap model drafts three materially different approaches; a strong model or a deterministic checker scores all three for a fraction of what any one cost to write. The harness rule: never fan out irreversible actions — fan out their rehearsals.

A serial agent defends its first answer because its first answer is all it has. A speculative agent can afford to be wrong in futures nobody will ever read.

Speculative decoding moved this pattern from CPUs to tokens; the next move is from tokens to plans. Only the winner touches real state. The pruned plans are not waste — they are logged and folded back into the router's priors.

The losers are the payload

The most underused signal in agent infrastructure is the discarded branch. A pruned future carries information the winner cannot. Systems that log only committed trajectories keep the survivorship-biased fraction of their own history — deleting precisely the map a router needs to make the next fork cheap.

The full loop: fork, spin up futures, verify cheaply, commit the survivor — and route the casualties through an autopsy queue that becomes negative priors. Every discarded future is a bet the system never has to place twice.

The budget rule: speculate when rehearsing N futures costs less than the probability of serial failure times the cost of unwinding a committed one. Teams fail this test only because they price rehearsals at full model rates. Price them as cheap drafts verified deterministically, and the inequality flips — a little further every time draft models get cheaper.
