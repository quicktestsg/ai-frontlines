The Loop Is a Router

Most agent systems are built around one model, and the loop that drives them treats every step as if it cost the same. It is becoming a liability — and a pricing error repeated every step of every run.

Start with the observation that agent loops are already heterogeneous in everything except the model. The same run reads files, writes code, shells out, parses errors, decides what to do next. Any engineer looking at this sequence would immediately partition it: parsing a two-line error is regex work; deciding whether a failing migration means a bug in the plan or a bug in the world is judgment work. Humans do this internally — System 1 handles the routine, System 2 gets recruited for the strange. Single-model loops collapse the partition: they pay frontier prices for regex work, then, perversely, frontier latency for it too.

Both loops execute the same steps; they differ only in who executes each one. The routed loop keeps the fast model as the default executor — escalation is reserved for steps that earn it. And escalation is not a takeover: the frontier model returns a decision and a rationale, and the fast model keeps driving.

What earns an escalation

The failure mode of naive routing is escalation by vibes: a classifier guesses whether a step is hard, guesses wrong in both directions. The fix is to notice that the signals which justify escalation are mostly already present in the harness. Stakes: does the step touch the world, and is the effect reversible? Novelty: has the ledger seen this pattern before? Budget: how much run remains? These are harness facts — cheap, deterministic, auditable — which is what makes routing an engineering discipline.

The router sits in the harness, between the ledger and the model call, and consumes signals that cost nothing: reversibility from the tool contract, stakes from the tool category, novelty from a pattern count over the ledger, budget from the run's accounting. A router built on harness facts fails legibly — the post-mortem says which flag was missing — where a vibe classifier fails mysteriously.

Escalation is not a takeover. The expensive model returns a decision, not the steering wheel — the moment it keeps the wheel, the system is no longer routed; it is a frontier loop with a cheap warm-up act.

Context is the currency the router spends

The genuinely hard problem is the handoff. Each model has a dialect, and when the fast model inherits a context full of frontier-model prose it reads it as gospel, deferring to an expensive framing even after new evidence has outdated it. The mitigation is not a universal dialect but structure: route the handoff through the ledger — the escalated model receives a projection, not a transcript, and what it returns is appended as an attributed decision event. Provenance is the whole game.

The naive handoff shares a transcript, and the transcript blends voices until attribution is unrecoverable — exactly when the fast model starts treating confident old prose as load-bearing truth. The structured handoff is not more polite; it is more lossless: facts, open questions, and signed decisions travel, dialect does not. Same discipline version control taught software — never let the artifact's history become folklore.

Two objections deserve answers. Is this premature optimization? No — the routing layer is also where the loop's judgment lives; a harness that can route can also gate, throttle, and abort, while a harness that cannot route can only watch. Does model-swapping wreck reliability? Only if the loop pretends the models are interchangeable tokens. A routed loop has more corners, and each is individually cheap to test because the router's decisions are deterministic. The single-model loop has one corner, and it is tested only by incidents.
