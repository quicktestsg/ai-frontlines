The Dry-Run Layer — Rehearsal Before Irreversible Acts

Agent stacks are biased toward action. The plan parses, the tools are wired, the loop is warm — so the agent fires. The cheapest safety mechanism is not better alignment. It is rehearsal: run the plan against a cheap shadow of the world before spending the real one.

The incident always reads the same. An agent was handed a database migration — forty ordered steps, each individually verified. But the plan was authored against a snapshot, and the world kept moving. The agent followed its plan with perfect fidelity and completed all forty steps. The checklist stayed green the entire way down. The failure was that the first time this plan ever truly ran was in production.

Two pipelines, same task. The top lane discovers mismatches at maximum cost. The bottom lane inserts one pass against a shadow world and gates real execution on the diff. The shadow does not need to be faithful everywhere — only in the places the plan intends to touch.

A rehearsal ladder, from cheapest to realest

Dry-running is a ladder: plan validation (re-read as a critic, check ordering and permissions — no execution), shadow execution (stub every side effect, record what each step would have done), sandbox execution (real tools, contained and reversible effects), and at the top, canary and two-key. The mistake is treating the ladder as fixed policy. Reading climbs zero rungs; deleting and sending climb to the top.

A compiler refuses to guess whether your program is type-correct — it checks, before the program ever runs. An agent harness without rehearsal is an interpreter with the type checker deleted: fast, obliging, and wrong in production.

The diff is the product

The naive framing is pass/fail. The product is the diff: intended end-state vs shadow prediction vs sandbox reality. Match — commit. Drift — actions succeeded but touched things the plan never named; the world model is stale, re-plan. Surprise — an action failed that the planner believed impossible; the single most valuable signal in the pipeline, a discovered unknown.

The diff resolves into three outcomes. Match earns a commit. Drift forces a re-plan — the world model quietly expired. Surprise is worth more than both: a discovered unknown, bought at sandbox prices, that should flow back into the planner's priors.

Risk times reversibility sets the rung

Rehearsing everything kills the feature in design review. Allocate by a two-axis classification at dispatch: blast radius times reversibility. Reading a file: no rehearsal. Writing scratch: plan validation. Migrating a database: sandbox, canary, two-key. Sending a customer message climbs high despite looking innocent — there is no unsend. And reversibility must be measured against an undo path that actually works; most 'reversible' actions are reversible only by another agent executing correctly, which is to say they are not.

Every action is classified at dispatch along two axes — blast radius and reversibility — and the cell picks the rung. Reads skip rehearsal. Bulk irreversible work gets sandbox, canary, and a second key. The trap: reversibility must be scored against undo paths that have themselves been rehearsed. An undo never executed is a hypothesis, not a control.

Rehearsal rot

A shadow world is a cache of reality, and it decays like one. When the dry run keeps reporting MATCH on plans that would fail in production, that is strictly worse than no dry run — it launders bad plans through a trusted gate. Countermeasure: replay recently committed executions against the shadow and track the disagreement rate as a fidelity budget. A dry-run layer that does not measure itself is confidence theater with a dashboard. Checking a plan is always cheaper than cleaning up after it.
