The System Prompt Is Legacy Code

Every system prompt starts as three lines and grows into four thousand words. It is a program executed by a stochastic interpreter, maintained by copy-paste, with no diffs, no tests, and no owner. That is not a prompt. That is legacy code.

There is a document in every agent codebase that began as three lines. You are an assistant. You have these tools. Be concise. Two years later, that document is four thousand words, and the paragraph nobody can name is the one everyone is afraid to remove.

The accretion pattern. Each snapshot is locally reasonable: a fix here, a policy there, a guardrail after an incident. The global result is a document that grows monotonically — because nothing in the process ever removes a paragraph.

A program with no compiler

The uncomfortable framing is this: a system prompt is a program. It is source code, written in a natural language, executed by a stochastic interpreter that gets replaced twice a year. Its bugs are not syntax errors; they are silent behavioral drift — the model complying with ninety-two percent of it, and nobody knowing which ninety-two.

Every paragraph is a scar

Read any mature prompt closely and you are reading an incident log written in the imperative mood. Each paragraph was a fix for something real. These fixes worked — or seemed to — and so they stayed. The prompt has no garbage collector. It only has allocation.

The cost of bloat is not just tokens. The deeper cost is dilution: instruction-following is a finite budget that every added paragraph must share. Each new clause quietly taxes every existing clause — and teams respond by adding another paragraph, instructing the model to really, truly follow the other paragraphs.

A prompt read as geology. The deepest layer is the founding text; every layer above it is history — incidents, policies, fossil examples, hotfixes. The team maintains eye contact with only the top layer. The rest is sediment that everyone fears and nobody maps.

The interpreter moves; the program doesn't

There is a second axis of decay, more treacherous than bloat: the prompt stays frozen while the interpreter moves. A model upgrade is a silent change of the virtual machine — same source, different semantics — and the team inherits a program compiled for a machine that no longer exists.

Nobody owns it, everybody patches it

Ownership is the third axis, and it compounds the other two. The prompt is edited by whoever is closest to the current fire. There is no diff, no review, no rollback. Its true change log lives in a chat thread and the memories of three people, two of whom have left the team.

A system prompt is a program that everyone edits and no one maintains. It grows one incident at a time, executes on an interpreter that changes without notice, and fails silently in proportion to its size. Legacy code at least has a version history. The prompt has folklore.

Ship it like code, shrink it like debt

The remediation is not exotic; it is everything software engineering already knows, applied without exception. The prompt lives in version control. Changes arrive as diffs, pass through the eval suite, and a regression is a rejection — not a judgment call made at midnight.

The prompt managed as an artifact. Edits arrive as diffs, pass a human review, then face the eval suite — regressions are rejected automatically, passes ship as new versions pinned to their model. Production telemetry feeds the list of deletion candidates, so the loop ends not in another paragraph, but in less prompt.

But the deeper discipline is subtraction: the best paragraph is the one never written. A rule in a prompt is a request. A rule in the harness is a fact. Every instruction that can be promoted from prose to structure should be — the prompt keeps only what genuinely requires judgment.

The test is simple and unflattering: delete one paragraph per week and watch the evals. A prompt that only ever grows is not being engineered; it is being endured. The work is keeping it nearly three lines, forever, while everything around it gets smarter.
