Forgetting Is a Feature

Agent memory is marketed on total recall: remember every conversation, every preference, every decision, forever. But an agent that remembers everything is an agent that drowns in its own history.

Runtime engineers solved a version of this problem decades ago, and their vocabulary fits disturbingly well. A program allocates memory constantly; almost none of it is still needed a minute later. The miracle of automatic memory management is not that it reclaims bytes — it is that it decides, without being told, which allocations are still live.

Generational garbage collectors exploit one empirical fact: most objects die young. Agent memory has the same shape. The ephemeral layer holds session scratch and should vanish by default. The episodic layer holds what happened and why, promoted only when something references it again. The semantic core is small, expensive, and hand-tended.

The false economy of total recall

The instinct behind remember-everything memory is an economy that does not exist: storage is nearly free, so remembering everything must be nearly free. This counts the wrong resource. The cost of a memory is not its storage — it is every future retrieval it participates in. Each recalled item consumes context window, attention, and the reader's trust; each stale item actively subtracts from all three.

A memory system is not judged by what it stores. It is judged by the average age of what it retrieves. Everything a long-lived agent recalls should have earned the right to be old.

There is a second cost that is harder to see: interference. In a human, forgetting is not failure — it is active suppression of what no longer predicts the present. An agent with perfect recall has no mechanism for a new fact to win. When the user changes their mind, the memory store now contains both positions with equal weight, and whichever one the retriever surfaces first wins the turn.

Mark, sweep, compact

The practical question is what liveness means for a memory, and the answer is behavioral, not semantic. A memory is live if it is referenced — not by other memories, which is how hoards rationalize themselves, but by decisions. The marking pass is a simple audit: did this memory change an action in the last N times it was retrieved? If it was retrieved ten times and changed nothing, it is paying rent in context and earning nothing.

The marking pass classifies each episodic memory by a behavioral test: was it retrieved, and did retrieval change an action? Items that pass are survivors, headed for compaction into canonical notes. Items that fail are swept to cold archive, retrievable only by a deliberate query. Nothing is destroyed; everything is ranked.

Compaction deserves its own paragraph because it is where most memory systems quietly fail. The failure mode looks like success: the store grows, retrieval still returns something plausible, nothing crashes. But the semantic core — the small set of statements the agent trusts enough to act on without re-checking — has stopped being maintained. An un-compacted core is not a knowledge base. It is a sediment layer with a search box.

Expiry dates for beliefs

There is a deeper design decision hiding under all of this: memories should carry their own decay model. Facts have different half-lives, and a store that treats them uniformly is systematically wrong about the most important ones. A user's name is effectively immortal; a preference has a half-life of months; a file layout, weeks; a sprint's priorities, days; the state of a working tree, minutes.

Every class of memory has a different confidence half-life, and a serious store encodes the prior at write time: identity barely decays, durable truths last years, preferences fade over months, layouts rot in weeks, session state is stale in minutes.

The uncomfortable conclusion is that the memory layer deserves more engineering attention than the recall layer, because recall quality is downstream of heap hygiene. A mediocre retriever over a small, current, well-cited heap beats a brilliant retriever over an unbounded sediment of stale assertions. Automatic allocation alone gives you a leak; collection is what turns a leak into a system. Forgetting, done deliberately, is the only mechanism by which what an agent knows stays true.
