# AI Frontlines

Curated AI news from the frontlines: **OpenAI**, **Anthropic**, **Google Gemini**, and **xAI Grok**.

No fluff. No clickbait. Just signal from the four labs shaping the frontier.

## Tech

- Pure HTML/CSS/JS — no build step, no framework
- Apple-inspired design with dark/light mode
- Animated gradient backdrop, staggered card animations
- Company filtering (OpenAI / Anthropic / Google / xAI)
- Auto-deploys to GitHub Pages on push to `main`

## Structure

```
index.html          — Feed page (card grid + filter)
about.html          — About page
style.css           — Full design system
app.js              — Theme toggle + filter logic
articles/           — Individual blog posts
.github/workflows/  — GitHub Pages auto-deploy
```
